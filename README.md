# 💨 Wind Turbine SCADA Performance Analysis

Análisis de datos (ETL, EDA y Visualización) sobre +50.000 registros SCADA de un parque eólico usando Python.

## 🛠️ Tecnologías
* **Python** (Pandas, NumPy, Matplotlib)
* **Power BI** (Próximamente)

## 📊 KPIs Principales
* **Registros:** 50,530
* **Viento Promedio:** ~7.08 m/s
* **Potencia Real Promedio:** ~1,924 kW
* **Eficiencia Operativa:** ~84.5%

## 📈 Contenido del Proyecto
1. **Limpieza y ETL:** Tratamiento de nulos, infinitos y fechas.
2. **Análisis Estacional:** Agrupación por mes (`groupby`).
3. **Visualización:** Comparativa de potencia (real vs teórica), viento por mes y curva de potencia (scatter plot).
4. **Exportación:** Generación de CSV procesado.
